## Esercitazione 8

## Metodi ricorsivi su liste e alberi binari di ricerca

Clonare il codice sul proprio IDE

1. Implementare i metodi di default della interface `ADTConsList`
2. Implementarei metodi della classe interna `RecBST` della classe
   `BinarySearchTree`.

Tutti i metodi da implementare contengono il
commento `// TODO implementare` o `// TODO implementare ricorsivamente`. In
questo ultimo caso è richiesta una implementazione ricorsiva. Per la classe
`BinarySearchTree` viene fornita una classe di test JUnit, mentre per la
interface `ADTConsList` viene fornito un main con degli esempi di uso.
