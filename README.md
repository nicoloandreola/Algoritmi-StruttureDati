## Esercitazione 6

### Liste concatenate

Implementare la classe `SingleLinkedList<E>`che implementa 
l'`interface` `List<E>`. La classe deve usare liste concatenate in una unica direzione, 
dalla testa alla coda. 

Non vanno implementati tutti i metodi, ma solo quelli che hanno il commento
`\\ TODO implementare`

Gli altri metodi hanno già preimpostato il lancio di una `UnsupportedOperationException`

Sono disponibili alcuni test JUnit nella classe di test fornita.
